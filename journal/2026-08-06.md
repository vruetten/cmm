# 2026-08-06

## Goal

Refactor `cmm` to a shippable standard: lean spectral core other packages can
import, coherence k-means + coherence spectral clustering, real test suite
validated against scipy/sklearn. Absorb the rewritten code from `icampsnfr`.

## Done

Read both repos end to end. Audited `cmm` (10 critical bugs, 6 silent-continue,
9 hygiene) and measured the dependency question rather than assuming it.
Plan written to `.claude/plans/cmm_refactor_plan.md`.

Verified by measurement, not inspection:

- `cmm.cmm` / `cmm_funcs` / `power_iteration` / `ana_funcs` do not import in the
  `all` env — jax is not installed. The `CMM` class is dead code.
- PSD normalization disagrees with `scipy.signal.welch`: `scaling="spectrum"`
  off by 21.3×, `"density"` off by 0.5× (missing one-sided doubling, so DC and
  Nyquist sit 2× high *relative* to interior bins). Reaches `icampsnfr`'s
  `frc.py`, `spectrum.py`, `traces.py`.
- Coherence is exact vs `scipy.signal.coherence` (8.9e-16) — normalization
  cancels in the ratio. This is the one known-good path.
- `estimate_spectrum(x_in_coefs=True)` returns a wrong frequency axis
  (`rfftfreq(2f-1)` where it needs `rfftfreq(2(f-1))`).
- project → backproject round-trip magnitude ratio is 0.044, not 1.

Benchmarks (`scratchpad/bench{1,2,3}.py`, **1-CPU affinity — needs re-running on
a real allocation**): dask genuinely wins 4× over naive blocked numpy on the
N×N per-frequency path and avoids up to 35 GB of intermediates. A
normalized-coefficient blocked float32 formulation beats dask 1.6–9.5× at 7e-8
error, but only under this affinity. jax contributes nothing measurable.

## Decisions

- Absorb from `icampsnfr`: `spectral.py`, the `coherence.py` MSC core,
  `phase.py`, `wavelet.py`. Hierarchical `cluster.py` out of scope (except its
  `1 - sqrt(C)` distance conversion, which fixes the inverted silhouette).
- Clean API break; patch `icampsnfr`'s 4 import sites in the same pass.
- No dependency removed until benchmarked on a real allocation and reported.
- **Coherence estimator: V2 everywhere** (power-weighted, incoherently averaged
  over frequency). Full four-way comparison in
  `derivations/coherence_estimators.md`. V3 (`icampsnfr.msc_matrix`, coherent
  averaging over f) is retired — it assumes constant phase across the band and
  scores a 10 s lag at 0.269 on perfectly coherent signals. V1 stays reachable
  as `whiten=True` for reproducing pre-refactor cmm results.

- **Q1** repair `estimate_wiener_r` into a documented `wiener_filter` (directed
  x→y measure that V2 cannot express). **Q2** four test-reference layers: scipy,
  a naive in-test reference implementation, analytic ground truth, and `mne` as
  a test-only extra. **Q5** complex64 / float32 by default, `dtype=` to opt out.
- **Q4** delete `power_iteration.py` — matrix-free never wins on the K×K
  centroid, measured at n=20k (K=10..240) and n=100k. But the scaling concern
  was right about the *other* eigenproblem: the N×N Laplacian in spectral
  clustering. Asking `eigsh` for the **largest** eigenvalues of
  S = D^-1/2 W D^-1/2 (λ_L = 1 - λ_S) instead of the smallest of L is 5.4×
  faster at N=10000 (20.8 s vs 112.9 s) and agrees to 3e-15. Dense is O(N³),
  Lanczos O(N²), so the gap widens. This makes the docstring claim in
  `icampsnfr/spectral.py` — that dense beats iterative up to N~20k — measurably
  false.

## Next

Three measurement gates before any code is removed:

1. Re-run `scratchpad/bench{1,2,3}.py` on a real multicore allocation and
   confirm the dependency policy (dask stays, jax goes).
2. Confirm the Lanczos speedup and agreement on a **real** coherence graph, not
   synthetic blocks — convergence depends on the spectral gap.
3. Test k-NN sparsification of the affinity: matvecs drop from O(N²) to
   O(N·k_nn), potentially a much larger win than 5.4×, if cluster structure
   survives it.

Then Phase 1 (`spectral.py` + scipy-validated tests).
